## 發布順序

1. 完成 P0 測試與安全審查。
2. 取得正式資料庫 migration 與正式網站部署授權。
3. 先套用資料庫 migration，立即驗證資料、RLS、RPC 與 Auth。
4. 合併 PR 並部署正式網站。
5. 以真實測試帳號完成註冊、登入、學習、同步、教師與管理員流程。
6. 通過所有發布閘門後，才將產品狀態標示為正式上線。
