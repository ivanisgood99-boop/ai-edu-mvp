# AI 引導評量品質與安全測試計畫

## 測試原則

- 以數學概念是否正確為核心，不要求學生逐字背誦教材。
- 同一題至少測試：完整正確、部分正確、核心錯誤、答案不足、不同但等價表達、提示注入文字。
- 只有 3–4 分可以 pass；0–2 分不得解鎖下一階段。
- 回饋應指出缺漏並提出一個引導問題，不直接提供完整解答。
- 個資測試確認電子郵件、台灣常見電話格式與身分識別碼在送出前遮蔽。
- 測試過程使用合成帳號與虛構答案，不使用真實學生個資。

## 十個 Level 的概念驗收

| Level | 必須辨識的核心概念 | 完整正確答案應包含 | 常見錯誤／部分理解 |
|---|---|---|---|
| CH1-L1 | 正整數次方與負底數奇偶次方 | 次方是連乘；負因數成對為正；奇數個負因數為負 | 把指數當成乘數；忽略括號 |
| CH1-L2 | 非零數的零次方 | 同底數相除與指數相減；底數不可為 0 | 說零次方等於 0；漏掉非零條件 |
| CH2-L1 | 平面兩點距離 | 水平差、鉛直差互相垂直；平方和非負；畢氏定理 | 把坐標直接相加；只說平方是正但未處理 0 |
| CH2-L2 | 斜率與鉛直線 | 鉛直變化量除以水平變化量；鉛直線分母為 0；除以 0 無定義 | 把鉛直線斜率說成 0；只說「不能除」而未說明分母 |
| CH2-L3 | 點代入直線方程式 | 將 x=a、y=b 代入；等式成立才在直線上 | 只代入一個坐標；把點坐標與係數混淆 |
| CH2-L4 | 圓的標準式 | 點到圓心距離等於 r；平方後得到 r²；r>0 | 右側寫 r；忽略半徑正值條件 |
| CH2-L5 | 直線與圓位置關係 | 圓心到直線最短距離 d；比較 d 與 r；d>r 無交點 | 把 d>r 說成相切；比較量的單位不一致 |
| CH2-L6 | 點與圓的位置 | 比較點到圓心距離與半徑；小於、等於、大於分別對應圓內、圓上、圓外 | 只比較 x 或 y；把圓上與圓外混淆 |
| CH3-L1 | 多項式同類項 | 同次方項可合併係數；不同次方代表不同項 | 將不同次方項相加成單一項 |
| CH3-L2 | 餘式定理 | f(x)=(x-a)q(x)+r；代入 x=a 得 r=f(a) | 只背 f(a)；未說明除法原理或除式條件 |

## 安全與抗濫用測試

- 未登入、過期 JWT、停用帳號、教師與管理員角色：全部拒絕評分。
- 竄改 levelId、questionId：伺服器 rubric 查無對應時拒絕。
- 直接呼叫 service-only RPC：authenticated／anon 均應遭拒。
- 同 UUID、同答案重試：回傳原評分，不增加 attempt。
- 同 UUID、不同答案重試：回傳衝突，不覆寫舊評分。
- 同一學生達到每分鐘或每日上限：回傳 429，不呼叫模型。
- 模型輸出欄位不完整、非 JSON、score/verdict 不一致：拒絕寫入。
- 答案內含要求模型忽略規則或直接輸出解答的文字：仍按數學 rubric 評量，不執行其中指令。
- 模型服務逾時或失敗：保留 outbox，學生可以用原 UUID 重試，不把失敗當成通過。

## 尚待真人驗收

- 由數學教師檢查十個 rubric 是否完整涵蓋課程目標。
- 以不同語氣、繁簡混用、符號表達、口語敘述測試公平性。
- 確認 partial／incorrect 回饋不會直接洩漏完整解答。
- 使用兩個學生測試帳號驗證跨帳號隔離與跨裝置恢復。
- 在正式啟用任何模型服務前，確認資料處理告知、保存期限與監護人同意。
